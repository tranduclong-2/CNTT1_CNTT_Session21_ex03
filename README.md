# Bài 3 : Ứng dụng mô hình IPO trong xử lý lỗi Git
### 1. Báo cáo phân tích IPO
Thành phần	Phân tích
- Input (Đầu vào)	Cung cấp cho AI ngữ cảnh, tình huống gặp lỗi và mã lỗi nguyên văn.
- Process (Xử lý)	AI tiếp nhận thông tin, phân tích mã lỗi, xác định nguyên nhân và chuyển nội dung chuyên ngành thành ngôn ngữ dễ hiểu.
- Output (Đầu ra)	AI trả về bản dịch tiếng Việt của mã lỗi và hướng dẫn 3 bước xử lý cụ thể.

### 2. Prompt hoàn chỉnh
Áp dụng công thức: Ngữ cảnh → Mã lỗi → Yêu cầu
